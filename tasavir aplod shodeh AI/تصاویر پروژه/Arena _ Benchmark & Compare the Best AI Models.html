۳. وصل کردن به سایت خودت

الف) تصویر آماده‌ی آپلود با فرمت مدرن

HTML
<picture>
  <source srcset="webp/01-headphones.webp" type="image/webp">
  <img src="01-headphones.jpg" alt="هدفون بی‌سیم" width="800" height="800"
       loading="lazy" decoding="async">
</picture>

width/height را همیشه بده (جلوگیری از پرش چیدمان = CLS)، و تصویر اصلی بالای صفحه را loading="eager" بگذار.

ب) حلقه‌ی متحرک محصول

HTML
<img src="animated/01-headphones-loop.webp" alt="هدفون بی‌سیم" width="520" height="520" loading="lazy">

اگر مرورگر WebP متحرک را پشتیبانی نکند، اولین فریم نمایش داده می‌شود (خراب نمی‌شود). برای پروژه‌های حیاتی می‌توانی <video autoplay muted loop playsinline> هم بگذاری.

ج) اسلایدر خودکار (کد اصلی همین دمو)

اسکلت کار به این شکل است:

HTML
<div class="slide active" style="--accent:#7cf0d8">…</div>
<script>
let i = 0, paused = false;
const slides = [...document.querySelectorAll('.slide')];
const show = n => { i = (n + slides.length) % slides.length;
  slides.forEach((s, k) => s.classList.toggle('active', k === i)); };
let timer = setInterval(() => show(i + 1), 6200);
// توقف هنگام هاور = تجربه‌ی کاربری بهتر
hero.addEventListener('mouseenter', () => { paused = true; clearInterval(timer); });
hero.addEventListener('mouseleave', () => { paused = false; timer = setInterval(() => show(i + 1), 6200); });
</script>

انیمیشن‌ها همه با @keyframes خالص CSS نوشته شده‌اند: floaty (شناوری) · blob (جابه‌جایی لکه‌های رنگ) · sheen (درخشش دکمه) · pulse · marq · spin. در فایل با Ctrl+F روی نام کی‌فریم بزن و کپی کن.

د) فرم آپلود

ساختار داده‌ی ساده و قابل انتقال به بک‌اند:

JavaScript
items = [{ id, name, size, url, progress, done }]

برای اتصال به سرور، فقط بخش simulate() را با XMLHttpRequest/fetch و رویداد upload.onprogress عوض کن:

JavaScript
const fd = new FormData(); fd.append('image', file);
const xhr = new XMLHttpRequest();
xhr.upload.onprogress = e => { if (e.lengthComputable) it.progress = e.loaded / e.total * 100; };
xhr.open('POST', '/api/products/upload'); xhr.send(fd);
