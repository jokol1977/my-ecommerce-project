# 📦 کیت تصاویر و انیمیشن فروشگاه

همه‌ی خروجی‌ها در یک نگاه. هر سه صفحه‌ی دمو **کاملاً خودکفا** هستند (تصاویر به‌صورت base64 داخل خود فایل)، پس بدون اینترنت و بدون سرور هم در پیش‌نمایش کار می‌کنند.

---

## ۱. فایل‌های دمو

| فایل | چیست | داخلش چه چیزی است |
|---|---|---|
| `animated-hero.html` | **بنر + اسلایدر متحرک** | ۵ اسلاید با پس‌زمینه‌ی گرادیانی متحرک، بلاب‌های شناور، حرکت شناور محصول، حلقه‌ی نوری، تگ‌های شیشه‌ای، نوار تخفیف نبض‌دار، نوار دسته‌بندی متحرک (marquee)، گرید ۱۶ کارت محصول با انیمیشن هاور و ورود با اسکرول |
| `upload-demo.html` | ** فرم آپلود متحرک** | کشیدن‌و‌رها (drag & drop)، هاله‌ی تنفسی، اعتبارسنجی فرمت/حجم، نوار پیشرفت انیمیشنی، پیش‌نمایش زنده، حذف با انیمیشن، پیام شناور (toast)، محاسبه‌ی حجم، نوار عملیات چسبان و جشن موفقیت با کانفتی |
| `gallery.html` | **گالری ۱۶ تصویر** | نمایش همه‌ی تصاویر با دسته‌بندی + گزارش حجم اصل/WebP |
| `product-images/manifest.json` | **فهرست متادیتا** | نام، دسته، استایل، ابعاد و حجم هر تصویر — برای اسکریپت آپلود خودکار |

## ۲. ساختار فایل‌های تصویر

```
product-images/
├── 01-headphones.png … 16-fantasy-cgi.png   ← اصل ۱۰۲۴×۱۰۲۴ (~۱ تا ۳ مگابایت)
├── webp/      800×800  WebP کیفیت ۸۲       ← آماده‌ی آپلود روی سایت (~۶ تا ۶۶ کیلوبایت)
├── thumbs/    400×400  WebP کیفیت ۷۸       ← کارت محصول و لیست‌ها
├── animated/  *-loop.webp                  ← حلقه‌های شناور متحرک (۱۳۹ تا ۴۲۷ کیلوبایت)
└── manifest.json
```

**تصاویر:** ۱۲ دسته‌بندی (دیجیتال، پوشاک، زیبایی، خانه، سفر، خوراکی، گیاه، ورزشی، جواهرات، اسباب‌بازی، لوازم برقی…) + ۳ استایل (لایف‌استایل با انسان، استودیو سفید مینیمال، صحنه‌ی خلاقانه CGI).

**بهینه‌سازی انجام‌شده:** ۲۸.۵ مگابایت → **۴۴۵ کیلوبایت** (۹۹٪ کاهش) فقط با تبدیل به WebP و ری‌سایز.

## ۳. وصل کردن به سایت خودت

### الف) تصویر آماده‌ی آپلود با فرمت مدرن
```html
<picture>
  <source srcset="webp/01-headphones.webp" type="image/webp">
  <img src="01-headphones.jpg" alt="هدفون بی‌سیم" width="800" height="800"
       loading="lazy" decoding="async">
</picture>
```
> `width/height` را همیشه بده (جلوگیری از پرش چیدمان = CLS)، و تصویر اصلی بالای صفحه را `loading="eager"` بگذار.

### ب) حلقه‌ی متحرک محصول
```html
<img src="animated/01-headphones-loop.webp" alt="هدفون بی‌سیم" width="520" height="520" loading="lazy">
```
اگر مرورگر WebP متحرک را پشتیبانی نکند، اولین فریم نمایش داده می‌شود (خراب نمی‌شود). برای پروژه‌های حیاتی می‌توانی `<video autoplay muted loop playsinline>` هم بگذاری.

### ج) اسلایدر خودکار (کد اصلی همین دمو)
اسکلت کار به این شکل است:
```html
<div class="slide active" style="--accent:#7cf0d8">…</div>
<script>
let i = 0, paused = false;
const slides = [...document.querySelectorAll('.slide')];
const show = n => { i = (n + slides.length) % slides.length;
  slides.forEach((s, k) => s.classList.toggle('active', k === i)); };
let timer = setInterval(() => show(i + 1), 6200);
// توقف هنگام هاور = تجربه‌ی کاربری بهتر
hero.addEventListener('mouseenter', () => { paused = true; clearInterval(timer); });
hero.addEventListener('mouseleave', () => { paused = false; timer = setInterval(() => show(i + 1), 6200); });
</script>
```
انیمیشن‌ها همه با `@keyframes` خالص CSS نوشته شده‌اند: `floaty` (شناوری) · `blob` (جابه‌جایی لکه‌های رنگ) · `sheen` (درخشش دکمه) · `pulse` · `marq` · `spin`. در فایل با `Ctrl+F` روی نام کی‌فریم بزن و کپی کن.

### د) فرم آپلود
ساختار داده‌ی ساده و قابل انتقال به بک‌اند:
```js
items = [{ id, name, size, url, progress, done }]
```
برای اتصال به سرور، فقط بخش `simulate()` را با `XMLHttpRequest`/`fetch` و رویداد `upload.onprogress` عوض کن:
```js
const fd = new FormData(); fd.append('image', file);
const xhr = new XMLHttpRequest();
xhr.upload.onprogress = e => { if (e.lengthComputable) it.progress = e.loaded / e.total * 100; };
xhr.open('POST', '/api/products/upload'); xhr.send(fd);
```

## ۴. چک‌لیست تست بارگذاری

- [ ] نسبت ۱:۱ و تصویر عمودی/افقی — آیا برش درست است؟
- [ ] فایل WebP متحرک — در کروم/فایرفاکس/سافاری موبایل نمایش می‌دهد؟
- [ ] فایل بزرگ‌تر از ۵ مگابایت — پیام خطا درست نشان داده می‌شود؟
- [ ] فایل غیرتصویری (PDF) — مسدود می‌شود؟
- [ ] بالا و پایین صفحه روی موبایل — نوار عملیات چسبان مزاحم نیست؟
- [ ] حالت `prefers-reduced-motion` — انیمیشن‌ها خاموش می‌شوند (در CSS لحاظ شده)

## ۵. نکته‌ی کیفیت در محصول واقعی

تصاویر این کیت **نمونه‌ی تست** هستند. برای محصول واقعی: نورپردازی استودیویی، حداقل ۳ زاویه (روبرو، ۴۵ درجه، جزئیات)، پس‌زمینه‌ی یکسان در همه‌ی محصولات، و گوشی/دستگاه واقعی در تصویر اندازه‌سنجی. عکس ضعیف، بیشتر از قیمت بالا مشتری را فراری می‌دهد.
